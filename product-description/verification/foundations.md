# Verification: foundations

How to run this file: bring up Studio as [the protocol](README.md#how-to-run-a-pass) describes, on the throwaway copy `verify-examples/`, with the four test compositions made, in a desktop Chromium-based browser at `http://127.0.0.1:5173/` with a window of at least 1600 by 900 pixels. Unless an item says otherwise, start it from **Fresh**. Items whose Device column says `disk` change files in the copy; each says what to undo, and anything else can be restored from `examples/` or by remaking the test composition. Run the items that add a `public/` folder (PROJECT-49) or a root-level `composition.html` (PROJECT-15 to PROJECT-17, and PROJECT-79) last in a session, because they change what every other item sees, and undo them before going on.

Setups named in the Setup column:

- **Fresh**: the site's local storage cleared (developer tools, Application, Local storage, `http://127.0.0.1:5173`, Clear all), the page reloaded, the layout at its defaults, and the composition that opens (Audio Visualization, on a first visit) left open.
- **Unbound**: the site's local storage cleared, `helios-studio:active-composition-id` set to `"verify-unbound"` (quotes included), and the page reloaded, so that Verify Unbound (150 frames) opens on the page load rather than by a switch, which can carry the previous composition's frame, props, and length into it (PLAYER-67 to PLAYER-74). Once it is connected (no message over it) it is paused at frame 0, with in point 0, out point 150, loop off, 1x, and volume and mute at their defaults. Put keyboard focus on the page by clicking the empty background of the timeline panel below the track area, a little above the panel's bottom edge: the panel's own horizontal scrollbar runs along that edge, and a click on it does not move focus. **Unbound, playing** is Unbound after pressing Space.
- **Media**: as Unbound, with `"verify-media"` (Verify Media, 600 frames, with audio, captions, a composition marker, and a schema).
- **Title**: as Unbound, with `"verify-title"` (Verify Title, clock-bound, connects).
- **Vanilla**: as Unbound, with `"verify-vanilla"` (Verify Vanilla, never connects).
- **Player focused**: from Unbound or Media, click the composition once (it starts playing), wait at least one second, and click it again (it pauses). The player now has keyboard focus. Never click the composition twice within a second, which is a double-click and enters fullscreen.
- "Set the playhead to N": click the timecode field, select all, type N, press Enter. "Set the in point to N": set the playhead to N, click the empty timeline panel background, press I (likewise O for the out point). These work only on a composition the transport can drive (Unbound, Media).
- "Read `key`": developer tools, Application, Local storage, the value of `helios-studio:key` (or of the `helios-layout-*` key named).

Device column: `mouse` (a wheel mouse; a trackpad is not a mouse), `keyboard`, `devtools` (Chromium's developer tools: Elements, Application storage, Network blocking and throttling), `disk` (an editor or shell on the files in `verify-examples/`), `server` (the terminal running `helios studio`: stop it with Ctrl+C and start it again with the same command), `second tab` (another tab of the same browser at the same address), `desktop file` (a file dragged in from the operating system's file manager), `Mac` or `Windows or Linux` (where Control and Command, or Alt and Option, behave differently), `blocked storage` (a profile whose site data for `127.0.0.1` is blocked in Chromium's settings), and `keyboard layout` (an operating system keyboard layout other than US English).
