# Verification: playback

How to run this file: run it in Studio launched with `helios studio` in a throwaway copy of `examples/` (see the README's [scope decisions](../README.md#scope-decisions)), in a desktop Chromium-based browser with a fresh profile, maximized on a display about 1920 pixels wide, at 100% page zoom, with the layout at its defaults (sidebar 250, inspector 300, timeline panel 300 pixels; drag a divider back if an item moved it), so that the timeline is about 1000 pixels wide at Fit. Every playback document describes a composition the player can drive, and every example and template is [clock-bound](../foundations/the-preview-player.md#clock-bound-compositions), so every item uses the fixtures below except the three that check that claim on an unmodified example (TRANSPORT-02, TIMELINE-82, and RANGE-66); run those three first, since nearly every other item assumes their answer. Switching from a connected composition carries its input props into the next one and can save them into that one's `composition.json` (see [switching compositions](../foundations/the-preview-player.md#switching-compositions)); after any item that switches, delete `defaultProps` from the fixtures' `composition.json` files and reload, and undo any other edit an item makes to a fixture before the next item. The Device column says what an item needs beyond the mouse and keyboard: `mouse` and `keyboard` are the input the steps use; `devtools` is the browser's developer tools (Application, Local Storage, for the `helios-studio:timeline:{ID}` record; Console with the composition's frame selected as the context, for its `helios` object); `terminal` is a shell in the project folder (for copying fixtures, editing files, and triggering hot reloads); `speakers` means the item is judged by ear; `render` means a server-side render or client-side export must finish and its frames be counted (`ffprobe -count_frames`, or the duration at 30 frames per second); `Mac` or `Windows/Linux` means that platform's keyboard; `second window` is another application's window beside the browser; `second tab` is a second Studio tab at the same address; `second project` is another folder served by `helios studio` at the same address; `desktop file` is a file dragged from the operating system's file manager; `stopwatch` is a timer.

  duration, fps: 30, inputProps: defaults, autoSyncAnimations: true,

  },

    { id: 'odd', time: 1.23, label: 'Odd' },
    { id: 'beat', time: 2, label: 'Beat' },

On the timeline this gives caption bars at 0.5 to 1.5 seconds (frames 15 to 45) and 3 to 4 seconds (90 to 120), orange composition markers Odd (1.23 s, frame 36.9) and Beat (2 s, frame 60), a green one Go (4.5 s, frame 135), a cyan time-prop marker Title In (1 s, frame 30), and one audio lane starting at 0.5 seconds. Before each TRACKS item, its Props Editor must show title "Tracks Test", subtitle "Outside the schema", and Title In `00:00:01:00`; if not, delete `defaultProps` from `tracks-test/composition.json` and reset it.

## Procedures used in the Setup and Steps columns

- **Reset {fixture}.** Open it in the Compositions panel and reload, so it opens on a page load. Go to its total frames and press O; go to 0 and press I; turn loop off if 🔁 is blue; reload; set the timeline zoom slider to Fit; focus off. It is now connected and paused at frame 0, in point 0, out point at its total frames, loop off, 1x, volume 100%, unmuted.
- **Go to N.** Click the timecode field, type N, press Enter.
- **Range A–B.** Go to A and press I, then go to B and press O.
- **Focus off.** Click the words "Helios Studio" in the header, so keyboard focus is on the page and not in a field or the player.
- **Player focus.** Click the composition twice (it plays, then pauses); the player keeps keyboard focus.
- **Fractional frame.** Press Space and then K about a second later, repeating until the timecode, counted in frames, is one less than "Fr:".
- **Hot-reload {ID}.** In the terminal, `echo >> {ID}/composition.html`; the player reloads the composition. For a hot reload during a drag, run `sleep 5 && echo >> {ID}/composition.html`, go back to the browser without clicking anything else, and start the drag within 5 seconds.
- **N px right of a point.** Estimated by eye. At Fit on a 1000-pixel timeline, 8 pixels are about 5 frames of Drive Long and about 1.2 frames of a 150-frame fixture, so a snap is easy to see on Drive Long and visible as a one-frame difference on the others.
