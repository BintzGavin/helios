# PERF-1102: Merge single-worker strategy loop blocks

## Focus Area
`packages/renderer/src/core/CaptureLoop.ts` around line 170-380 in the single worker capture loops path. Specifically, merging identical loops nested under `isDomStrategy` conditional block to reduce V8 AST complexity.

## Background Research
Currently in `CaptureLoop.ts` within the `if (poolLen === 1) {` single worker execution block, we have an `if (isDomStrategy)` check wrapped around the bulk of the chunk loop (frames iteration logic). Inside both the `if (isDomStrategy)` branch and the `else` (Canvas Strategy) branch, there is extremely duplicated logic: `let i = 1; while (i < totalFrames - 1 && !aborted) { ... }` chunk logic.

As seen in PERF-1100, which successfully folded and merged similar blocks for multi-worker chunk loops by stripping the `isDomStrategy` wrapper and casting variables uniformly, we can perform the exact same AST reduction here for the single-worker path. The single worker loops also possess initial frame setups `if (totalFrames > 0)` which can be merged into a single implementation, avoiding duplicating the whole loop structure.

The difference lies mostly in parsing the screenshot buffer:
```typescript
const data = rawResult?.screenshotData;
if (data) {
  domLastFrameBuffer = Buffer.from(data as string, "base64");
}
```
For Canvas, the `rawResult` is the Buffer itself. For DOM, it's an object with `screenshotData`.

Merging these loops reduces closure parsing and function size significantly for the JS engine.
