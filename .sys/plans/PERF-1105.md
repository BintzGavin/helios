# PERF-1105: Unroll `isDomStrategy` single-worker final chunk loops

## Focus Area
The single-worker fast path main loop logic in `packages/renderer/src/core/CaptureLoop.ts` (around lines 244-332) where `isDomStrategy` branches repeatedly.

## Background Research
Currently, the single-worker path has an inner `for` loop, and a final loop cleanup block where `isDomStrategy` is repeatedly evaluated:

```typescript
        let i = 1;
        while (i < totalFrames - 1 && !aborted) {
          const chunkEnd = Math.min(nextProgress, totalFrames - 1);

          for (; i !== chunkEnd; i++) {
            const rawResult = await nextCapturePromise;

            const timePromise = timeDriver.setTime(page, (startFrame + i + 1) * compTimeStep);
            if (timePromise) await timePromise;

            if (isDomStrategy) { // CHECK 1
              if (!aborted) {
                nextCapturePromise = domBeginFrame!((i + 1) * timeStep);
              }
            } else {
              if (!aborted) {
                nextCapturePromise = strategy.capture(page, (i + 1) * timeStep);
              }
            }

            let buf;
            if (isDomStrategy) { // CHECK 2
              const data = (rawResult as any).screenshotData;
              if (data) {
                domLastFrameBuffer = Buffer.from(data as string, "base64");
              }
              buf = domLastFrameBuffer!;
            } else {
              buf = rawResult;
            }

            pendingBytes += buf.length;
            if (!stream.write(buf) && pendingBytes >= 16777216) {
              await this.drainPromise;
              pendingBytes = 0;
            }
          }

          if (aborted) break;

          // ...
        }

        if (!aborted && totalFrames > 1) {
          try {
            const rawResult = await nextCapturePromise;

            let buf;
            if (isDomStrategy) { // CHECK 3
              // ...
            } else {
              // ...
            }
```

Since the initial chunk parsing is already split by `isDomStrategy` (due to PERF-1104), and we know whether we are in a DOM or non-DOM path, we can simply split the *entire* `while (i < totalFrames - 1 && !aborted)` loop and final `if (!aborted && totalFrames > 1)` block to reside completely inside the respective `if (isDomStrategy)` and `else` blocks that already exist from PERF-1104. This completely removes the `isDomStrategy` check from the tight inner frame-processing loop for single-workers, unrolling the logic and dramatically improving JIT compilation and V8 branch prediction.

## Implementation Spec

### Step 1: Hoist and unroll the `while` and final frame loop inside the `isDomStrategy` blocks.
**File**: `packages/renderer/src/core/CaptureLoop.ts`
**What to change**:
Currently, we have:

```typescript
        if (isDomStrategy) {
          // [initial frames block]
        } else {
          // [initial frames block]
        }

        let i = 1;
        while (i < totalFrames - 1 && !aborted) {
           // ... contains `if (isDomStrategy)` checks ...
        }
        if (!aborted && totalFrames > 1) {
           // ... contains `if (isDomStrategy)` checks ...
        }
```

We will modify this to:

```typescript
        if (isDomStrategy) {
          // [existing initial frames block]

          let i = 1;
          while (i < totalFrames - 1 && !aborted) {
            const chunkEnd = Math.min(nextProgress, totalFrames - 1);
            for (; i !== chunkEnd; i++) {
              const rawResult = await nextCapturePromise;
              const timePromise = timeDriver.setTime(page, (startFrame + i + 1) * compTimeStep);
              if (timePromise) await timePromise;
              if (!aborted) {
                nextCapturePromise = domBeginFrame!((i + 1) * timeStep);
              }
              const data = (rawResult as any).screenshotData;
              if (data) {
                domLastFrameBuffer = Buffer.from(data as string, "base64");
              }
              let buf = domLastFrameBuffer!;
              pendingBytes += buf.length;
              if (!stream.write(buf) && pendingBytes >= 16777216) {
                await this.drainPromise;
                pendingBytes = 0;
              }
            }
            if (aborted) break;
            if (i === nextProgress) {
              nextProgress += progressInterval;
              console.log(`Progress: Rendered ${i - 1} / ${totalFrames} frames`);
              if (onProgress) {
                onProgress((i - 1) / totalFrames);
              }
            }
          }
          if (!aborted && totalFrames > 1) {
            try {
              const rawResult = await nextCapturePromise;
              const data = (rawResult as any).screenshotData;
              if (data) {
                domLastFrameBuffer = Buffer.from(data as string, "base64");
              }
              let buf = domLastFrameBuffer!;
              pendingBytes += buf.length;
              if (!stream.write(buf) && pendingBytes >= 16777216) {
                await this.drainPromise;
                pendingBytes = 0;
              }
              i++;
              if (i === nextProgress || i === totalFrames) {
                if (i === nextProgress) nextProgress += progressInterval;
                console.log(`Progress: Rendered ${i - 1} / ${totalFrames} frames`);
                if (onProgress) {
                  onProgress((i - 1) / totalFrames);
                }
              }
            } catch (e) {
              if (!aborted) throw e;
            }
          }
        } else {
          // [existing initial frames block]

          let i = 1;
          while (i < totalFrames - 1 && !aborted) {
            const chunkEnd = Math.min(nextProgress, totalFrames - 1);
            for (; i !== chunkEnd; i++) {
              const rawResult = await nextCapturePromise;
              const timePromise = timeDriver.setTime(page, (startFrame + i + 1) * compTimeStep);
              if (timePromise) await timePromise;
              if (!aborted) {
                nextCapturePromise = strategy.capture(page, (i + 1) * timeStep);
              }
              let buf = rawResult;
              pendingBytes += buf.length;
              if (!stream.write(buf) && pendingBytes >= 16777216) {
                await this.drainPromise;
                pendingBytes = 0;
              }
            }
            if (aborted) break;
            if (i === nextProgress) {
              nextProgress += progressInterval;
              console.log(`Progress: Rendered ${i - 1} / ${totalFrames} frames`);
              if (onProgress) {
                onProgress((i - 1) / totalFrames);
              }
            }
          }
          if (!aborted && totalFrames > 1) {
            try {
              const rawResult = await nextCapturePromise;
              let buf = rawResult;
              pendingBytes += buf.length;
              if (!stream.write(buf) && pendingBytes >= 16777216) {
                await this.drainPromise;
                pendingBytes = 0;
              }
              i++;
              if (i === nextProgress || i === totalFrames) {
                if (i === nextProgress) nextProgress += progressInterval;
                console.log(`Progress: Rendered ${i - 1} / ${totalFrames} frames`);
                if (onProgress) {
                  onProgress((i - 1) / totalFrames);
                }
              }
            } catch (e) {
              if (!aborted) throw e;
            }
          }
        }
```

**Why**: By unrolling the loops, we avoid re-evaluating `isDomStrategy` for every frame in the inner loop and final block. This significantly reduces AST parsing size for these hot loops, leading to better V8 optimization.
